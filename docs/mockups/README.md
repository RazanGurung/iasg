# Mockups

Static HTML, fabricated data, no backend. These are the design spec — match
them when building the real screens.

| File | Screen | Status |
|---|---|---|
| `client-console-v2.html` | Client console, read-first | **current** |
| `client-console-v1.html` | First pass, form-style | superseded — kept for comparison |
| `sales-tax-batch.html` | Monthly sales tax batch grid | current |
| `new-client-form.html` | New client creation | current |

v1 vs v2 shows the read-first change: v1 draws every field as an input box,
which suits data entry the app does not actually do. v2 renders values as text
with an explicit edit mode.

Still to design: Financial Statements module, the six reports, Credentials
vault UI, and the firm-wide worklists (Tasks, Additions/Closures, Annuals).
