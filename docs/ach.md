# ACH file generation

`Create Monthly Fees ACH Data File` produces a fixed-format file that debits
clients' bank accounts for the firm's fees.

**This is the highest-risk deliverable in the project.** A malformed batch is
either rejected by the bank or debits the wrong amounts from real client
accounts.

## Rules

- Treat as its own workstream with its own tests. Not "one of the reports".
- Reproduce the current output **byte for byte** before changing anything.
  Generate from both systems for the same period and diff.
- NACHA formatting is unforgiving: fixed 94-character records, specific
  padding, block counts in multiples of 10, and a checksum in the control
  records.
- Validate against the bank's test facility before any production run.
- Routing numbers get an ABA checksum test at entry (implemented in the
  new-client mockup) and again before file generation.
- Never write a partial file. Generate to a temp path, validate, then move.
- Log every generated file: period, client count, total debit amount,
  generated by, timestamp. Keep the files.
- A generation run must be repeatable and idempotent — re-running a period
  must not double-debit anyone.
